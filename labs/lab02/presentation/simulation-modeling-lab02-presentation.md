# Модель SIR

## Теоретическое описание

- Уравнения модели:
    - dS/dt = -β * c * (I * S) / N
    - dI/dt = β * c * (I * S) / N - γ * I
    - dR/dt = γ * I
- S – восприимчивые, I – заразные, R – переболевшие, N = S+I+R.
- Базовое репродуктивное число R0 = (c * β) / γ.

# Модель Лотки–Вольтерры

## Теоретическое описание

- Уравнения модели:
    - dx/dt = α * x - β * x * y
    - dy/dt = δ * x * y - γ * y
- x – численность жертв, y – хищников.
- Равновесие: x* = γ / δ, y* = α / β.
